Rust for Solana, at the systems level.

I write Rust for Solana. Most of my work sits below where frameworks start: real-time chain ingestion over Geyser gRPC, transactions assembled instruction by instruction against program IDLs, and an execution path that sizes priority fees and Jito tips per trade from live market state. Above that I build the APIs, dashboards and operational tooling a running system needs.

Day to day that means PDA derivation, account layouts, Token-2022 quirks, ATA lifecycles, wSOL handling, compute-unit budgeting, simulation and confirmation logic. From on-chain programs to the infrastructure around them, one person, end to end.

Private production system

Automated trading infrastructure on Solana. A 24-crate Rust workspace: Yellowstone Geyser gRPC ingestion, protocol decoders for the venues it trades, GPU-resident strategy evaluation, and a real transaction execution path carrying live capital. It has been running continuously on mainnet since 2026 and I maintain it alone.

The source is private. Available to review under NDA. No wallet addresses or transaction history are published, mine or the system's.
