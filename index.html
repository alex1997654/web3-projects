Example projects

Public examples, built to be inspected rather than admired. Each one is a devnet-deployed program with tests running in CI and a writeup of the design decisions. They are being published as they land:

Anchor escrow

Two-party SPL token escrow. The maker locks an offer of token A into a PDA vault and asks for token B in return. A taker pays the proportional share and receives the matching slice in one transaction, or takes the whole remaining offer at once. Partial takes round the owed token B up, against the taker, so the maker never eats rounding debt. Expiry is a strict boundary and refund is maker-only.

Twelve integration tests run the lifecycle in CI: full and partial takes, takes at the boundary, expiry enforcement, and a non-maker cancel attempt that fails on the PDA seed constraint.

Token-2022 vesting

Anchor program for Token-2022 vesting: cliff plus linear release, multiple schedules per beneficiary, and revocation that returns only the unvested part. Twelve integration tests cover the claim edges, from the cliff boundary to maturity, over-claiming and concurrent schedules. The interesting part is the account handling: this chain's Token-2022 writes 170-byte token accounts where anchor-spl models 165, and deserializing them traps the program. So the program treats token accounts as raw AccountInfo, reads balances from fixed base offsets, and packs every Token-2022 instruction by hand.

Chain activity dashboard

A live on-chain activity dashboard that runs entirely in the browser. One WebSocket to a public RPC endpoint, transaction logs for a chosen program, and Anchor events decoded from the raw log lines client-side, with session stats alongside: events per minute, cumulative SOL volume where events carry amounts, and the top interacting wallets of the session.

No backend, no database, no build-time secrets. The default view watches pump.fun's bonding curve program on mainnet; the memo program and Jupiter at instruction level are one click away.
